# Portrait prompts for every CHOICES character

Paste each prompt into an image app (or send it to an artist). Ask for **portrait orientation, 4:5**, head and shoulders, face in the upper half.
Save the result as `art/portraits/<file>.png` using the file name shown, then send me the images so I can add them.

Shared style (already included in every prompt):
> Modern comic-book cover illustration with the polish of a glossy 2004 fashion editorial. Realistic proportions, expressive almond eyes with detailed lashes and catchlights, glossy detailed lips, defined brows, painted hair with individual strands and warm highlights, confident ink linework with painterly rendering, cinematic golden-hour lighting. Palette: dusty rose, mauve, cream, warm ivory, cocoa, soft plum, champagne gold. No chibi, no flat vector, no anime-sprite style.
